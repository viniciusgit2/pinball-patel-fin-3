DESCRIÇÃO DO PROJETO
================================================================================

Pinball Patel Fin é um jogo de pinball desenvolvido inteiramente do zero 
utilizando HTML5, CSS3 e JavaScript puro (Vanilla JS). O jogo apresenta 
física realista, efeitos visuais neon, sistema de pontuação com combos e 
efeitos sonoros interativos.

Este projeto foi desenvolvido completamente de forma original por Vinicius 
Patel Fin, sem cópia de código de terceiros.


================================================================================
RECURSOS DO JOGO
================================================================================

✓ Física realista de pinball com gravidade e colisões
✓ 3 Flippers controláveis (esquerdo, direito e central)
✓ Sistema de lançamento de bola (plunger)
✓ 7 Bumpers interativos com pontuações variadas
✓ 4 Alvos especiais
✓ Sistema de combos que aumenta a pontuação
✓ Efeitos visuais neon e partículas
✓ Sistema de áudio com efeitos sonoros sintéticos
✓ Música de fundo durante o jogo
✓ Sistema de High Score salvo localmente
✓ Interface responsiva e moderna


================================================================================
CONTROLES
================================================================================

→ Seta ESQUERDA (←): Ativa o flipper esquerdo
→ Seta DIREITA (→): Ativa o flipper direito
→ Seta PARA CIMA (↑): Ativa o flipper central
→ ESPAÇO: Lançar a bola (segure para carregar, solte para lançar)


================================================================================
TECNOLOGIAS UTILIZADAS
================================================================================

• HTML5 Canvas - Para renderização gráfica do jogo
• CSS3 - Estilização com efeitos neon e animações
• JavaScript (Vanilla) - Lógica do jogo e física
• Web Audio API - Geração de efeitos sonoros sintéticos
• HTML5 Audio API - Reprodução de música de fundo
• LocalStorage - Armazenamento do High Score

================================================================================
COMO EXECUTAR O JOGO
================================================================================

1. Método Simples (Abrir diretamente):
   - Abra o arquivo index.html em um navegador web moderno
   - Recomendado: Chrome, Firefox, Edge ou Safari

2. Método com Servidor Local (Recomendado):
   - Abra um terminal na pasta do projeto
   - Execute: python3 -m http.server 8000
   - Acesse: http://localhost:8000 no navegador

3. Requisitos:
   - Navegador web moderno com suporte a HTML5 Canvas
   - JavaScript habilitado
   - Suporte a Web Audio API (para efeitos sonoros)
