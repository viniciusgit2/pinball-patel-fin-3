# Pinball Patel Fin 3.2

Jogo de Pinball com sistema de tradução multilíngue desenvolvido com Electron.

## Recursos

- Sistema de física realista
- Tradução multilíngue (PT-BR, EN, ES, FR, DE, IT, JA, KO, ZH)
- Interface gráfica moderna
- Efeitos sonoros
- Sistema de pontuação

## Instalação

### Linux
```bash
chmod +x install-linux.sh
./install-linux.sh
```

### Windows
```cmd
install-windows.bat
```

## Executar

Após instalação, use:
- Linux: `./setup-linux.sh` ou `npm start`
- Windows: `setup-windows.bat` ou `npm start`
